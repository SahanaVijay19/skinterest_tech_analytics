# skinterest_tech_analytics

Project Title: Data Analytics for Marketing. 

Models/Algos we are using: Sentiment Analysis (Classification/ Predictive Modelling) and Clustering.

As part of the Break Through Tech AI/ML fellowship, fellows undertake a Fall AI Studio Project. For my project, I am part of a team of 5 people who are addressing a business concern for Skinterest Tech, a startup based in NY. We are following the Agile Development methodologies and the CRISP-DM lifecycle. We are performing data analytics for community engagement-driven marketing via sentiment analysis and classification of Kaggle Sephora skincare data and customer segmentation. This project is still ongoing, to be completed in December; hence, not all the project repos are fully updated yet. Here are some of the things we have been working on together:

● Harnessing Numpy, Pandas for Data Processing, Keras for Modelling, Scikit Learn for K-means, hierarchical clustering, NLTK for NLP, etc.

● Achieved model accuracies of over 80 percent (accuracy is still being tested, and code is constantly being tweaked) and low validation loss. 

In this project repo, I will document our code for each sprint/milestone.
